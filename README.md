# ColombiaMedHistory

Prototipo de plataforma unificada de historiales médicos en la nube para Colombia.

## Descripción del Proyecto
Este proyecto es una propuesta académica para el módulo de Competencias Digitales (TICs), enfocado en diseñar una interfaz web intuitiva que permita consultar y registrar historiales médicos unificados a nivel nacional.

## Características
- Barra de navegación superior con diseño limpio e iconos temáticos.
- Buscador rápido por número de documento con carga asíncrona de datos desde un archivo JSON estático.
- Visualización de datos personales, tipo de sangre, alergias, diagnósticos y exámenes clínicos.
- Formulario de registro para nuevos pacientes.
- Compatible con GitHub Pages (sin dependencias de backend complejas, solo HTML, CSS y JavaScript).

## Estructura de carpetas
- `index.html`: Página principal con el buscador y presentación del sistema.
- `css/styles.css`: Hoja de estilos del proyecto.
- `js/app.js`: Lógica de consulta del historial clínico.
- `js/registro.js`: Lógica para el formulario de registro.
- `data/pacientes.json`: Base de datos de ejemplo con pacientes y diagnósticos simulados.
- `pages/registro.html`: Página de registro de nuevos pacientes.
